Dot-form alias for the **adr-tools** skill.

Run `adr init <directory>` in the shell, where `$ARGUMENTS` is the optional directory (defaults to `doc/adr`). Creates the ADR directory, writes `.adr-dir`, and seeds `0001-record-architecture-decisions.md`. Do not create the directory or seed file by hand.
